I'm a Computer Science and Mathematics student at the University of Maryland, graduating in May 2027. I work mostly on backend systems and cloud infrastructure.

Right now I'm a Software Engineer Intern at [Easy Dynamics](https://www.easydynamics.com), building multi-region Azure network infrastructure in Terraform and validating reusable modules against NIST 800-53 and federal compliance standards. Before that I built a retrieval and agent workflow for customer-support drafting at Mindgrasp, and spent two years at EchoIT in Seoul working across a Java and Spring Boot backend — including a Redis caching layer that took P95 API latency from 200 ms to under 30 ms.

I'm interested in the parts of a system where correctness and latency both matter: caching, asynchronous messaging, and infrastructure that fails loudly before it fails quietly. My [CV](/cv/) has the full details, and a few things I've built on my own are on the [projects](/projects/) page.
