# youngjaek.github.io

Youngjae Kim's personal website, built with [al-folio](https://github.com/alshedivat/al-folio) and hosted on GitHub Pages.

## Add a blog post

1. Copy `_drafts/post-template.md` to `_posts/YYYY-MM-DD-short-title.md`.
2. Replace the title, date, description, and body.
3. Commit and push to `main`. The deployment workflow publishes the rebuilt site to `gh-pages`.

Posts support Markdown, code blocks, math, images, tags, and categories through al-folio.

## Local preview

Run `docker compose up`, then open `http://localhost:8080`.
